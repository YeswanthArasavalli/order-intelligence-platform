## 12. Clean Acquisition/Load Evidence

### What was actually acquired independently

The two exact official GitHub Linux/amd64 binaries were streamed from remote HTTPS sources without reading Docker cache, reusing a local binary, or retaining downloaded files. Both full-byte hashes matched GitHub metadata/checksum files. This proves a cache-independent **binary** acquisition mechanism from this environment; it is not a clean Docker **image** acquisition/load test or a second-machine certification.

Exact binary acquisition command:

```bash
python3 -B -c 'import urllib.request,json,hashlib,struct,concurrent.futures
entries=[("minio","RELEASE.2024-11-07T00-52-20Z",103751832,"c27873d791b56d33518de11f12c5bfae4be88ebac00e12c6dd0027b08123fd80"),("mc","RELEASE.2024-11-05T11-29-45Z",27992216,"a2b886f974c4b32ee57c5bf6f3c8070bc4ac8a62ce3556cc241514aeb5427bd1")]
```
